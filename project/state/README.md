# project/state/

Cada tarefa cria aqui a sua própria pasta: `task-<id>/`.

Dentro dela ficam os handoffs de cada agente (`handoff-01-developer.md`,
`handoff-02-tester.md`, `handoff-03-code-reviewer.md`) e um `gates.md` com o
estado final dos gates aplicáveis.

Esta pasta pode ser apagada/arquivada no fim de cada tarefa concluída — não é
código do projeto, é só o histórico de coordenação da equipa de agentes.
